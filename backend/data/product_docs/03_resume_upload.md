# Resume upload and parsing

## Supported files
You can upload a resume as a PDF or DOCX file of up to 5 MB on the Resumes page. Drag the file onto the upload area or choose it with Browse files. Other file types are rejected.

## What is extracted
After upload, the resume is parsed automatically. The application extracts your contact details, summary, skills, education, work experience, projects, certifications and similar sections, and normalises your skills to a standard skill catalogue so they can be compared with internship requirements.

## Checking and fixing the result
Open a resume on the Resumes page to see what was extracted. If something was read wrongly, choose Edit details, correct it and save: your corrected version is used for matching, documents, readiness, comparison and both assistants, and the original file is never changed. Re-parse reads the stored file again with the parser (this replaces your corrections). Your preferred resume version, or else the latest successfully parsed one, is used for matching, skill gaps and the assistants.

## Downloading and deleting
You can download the original file at any time. Deleting a resume is permanent: it removes the file, its extracted information, skills, match results and skill-gap recommendations based on it. Generated documents and practice sessions are kept but no longer linked to it. You must type DELETE to confirm.
